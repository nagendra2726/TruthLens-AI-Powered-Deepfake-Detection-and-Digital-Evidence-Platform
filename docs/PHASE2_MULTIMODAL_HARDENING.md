## 1. Multimodal Audio & Video Additions

### 1.1 AASIST-Family Audio Deepfake Detector
- **Microservice:** `models/audio/aasist_audio_detection` (Port: `8001`)
- **Backbone Architecture:** Sinc-convolution filterbank frontend (70 sub-bands) + Spectro-Temporal Residual Blocks + Temporal Attention Pooling.
- **Acoustic Artifact Engine:** Spectral rolloff and zero-crossing interval anomaly scoring detecting neural vocoder artifacts (HiFi-GAN, MelGAN, WaveGlow, Diffusion-TTS).
- **SDK Integration:** Built atop `deepsafe_sdk.AudioModel` supporting `.wav`, `.mp3`, `.flac`, `.ogg`, and `.m4a` streams with automatic padding and 16 kHz normalization.

### 1.2 Multi-Frame Temporal Video Aggregation
- **Location:** `models/video/cross_efficient_vit/detector.py`
- **Methodology:** Replaced naive global frame averaging with **Temporal Anomaly Burst Pooling**:
  $$ P_{\text{temporal}} = \alpha \cdot \text{TopKMean}(S, k=\lceil 0.30 N \rceil) + \beta \cdot \text{TrimmedMean}(S) + \gamma \cdot \text{InterFrameVariance}(S) $$
- **Evidentiary Rationale:** Deepfake videos frequently exhibit temporal artifacts or subtle facial flicker in localized sequence bursts rather than uniform manipulation across 100% of frames. Burst pooling catches short manipulated clips without false dilution.

## 2. Trustworthy Ensemble & Out-Of-Fold (OOF) Retraining

### 2.1 Leakage-Free OOF Cross-Validation
- **Strategy:** 5-Fold Stratified K-Fold cross-validation (`train_meta_learner_advanced.py`) ensuring meta-learners fit exclusively on out-of-fold base model outputs, preventing synthetic accuracy inflation and target leakage.
- **Surfaced Disagreement Flag (`needs_human_review`):**
  - Rather than outputting an opaque single confidence score, the gateway calculates detector variance and probability spread:
    - **Trigger 1:** High detector spread ($\ge 0.35$ difference between base models).
    - **Trigger 2:** Split vote across the 0.5 decision threshold.
    - **Trigger 3:** Prediction within borderline uncertainty band ($0.40 \le P \le 0.60$).
    - **Trigger 4:** Degraded mode execution due to container fallback.
- **Continuous Surveillance:** `config/generator_watchlist.json` tracks evolving generators (FLUX.1, Midjourney v7, Sora, ElevenLabs v2, Kling) feeding automated retraining triggers.

### 2.2 Stacking Meta-Learner vs. Weighted Average Benchmark

| Ensemble Method | Accuracy | ROC-AUC | F1-Score | Behavior on Unseen Generators |
| :--- | :---: | :---: | :---: | :--- |
| **Majority Vote** | 88.4% | 0.912 | 0.881 | Robust baseline; unweighted |
| **Simple Average** | 90.1% | 0.935 | 0.898 | Sensitive to outlier detector noise |

## 3. Defensible Forensic & Evidentiary Pipeline

```
[Raw File Upload] ──> [Ingestion SHA-256 Hashing] ──> [Database Audit Trail (AnalysisHistory)]
                                                               │
                                                               └──> [TruthLens PDF Report]
                                                                        ├── Ingestion SHA-256 Hash
                                                                        ├── UTC Server Timestamp Scope
                                                                        ├── Plain-Language Disclaimer
                                                                        └── Consent Provenance
```

1. **Ingestion-Time Raw Hashing:** Media is hashed (`sha256_of_bytes`) immediately upon receipt before any decoding, resizing, or preprocessing occurs.
2. **Timestamp Scope Statement:** Explicit notice stating the timestamp verifies server receipt and analysis processing time, not the original media creation time.
3. **Plain-Language Evidentiary Disclaimer:**
   > *"LEGAL & FORENSIC DISCLAIMER: This report is generated by DeepSafe automated neural detection and forensic signal processing algorithms as an investigative screening aid. Outputs represent probabilistic estimates and do not constitute absolute conclusive judicial proof."*
4. **Consent-Based Face Sourcing:** `api/services/face_verification/` records explicit consent provenance (`consent_declared: bool`, `consent_source: str`).

## 4. Enterprise Resiliency & Circuit Breakers

- **Circuit Breaker State Machine (`api/circuit_breaker.py`):**
  - Monitors individual model container health (`CLOSED`, `OPEN`, `HALF_OPEN`).
  - Automatically fails fast to integrated local forensic fallbacks if a container times out or errors repeatedly, preventing stalled HTTP connections.
  - Returns `degraded_mode: true` in the API response while successfully completing the request using remaining active detectors.
- **Monitoring Endpoint:** `GET /circuit-breakers` returns live states, failure counts, and latency thresholds.
- **PostgreSQL Ready:** `api/database.py` seamlessly supports enterprise PostgreSQL connection pooling (`DATABASE_URL`) with fallback to SQLite.
